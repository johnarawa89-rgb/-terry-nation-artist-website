TERRY NATION WEBSITE — STARTER PACKAGE

This package contains a responsive black-and-gold artist website and a starter Pages CMS configuration.

IMPORTANT:
- The static website can be deployed to Netlify.
- A working content editor requires connecting the GitHub repository to a CMS provider and checking its current configuration requirements.
- Pages CMS is a separate service that can connect to GitHub repositories. Visit https://pagescms.org/ and sign in with GitHub after the website files have been added to your repository.
- Do not upload this ZIP file itself as the site. Extract it first, then upload the contents (index.html, images folder, pages.yml, README.txt) to the repository or deploy the extracted site folder.
- Replace placeholder streaming/social links with Terry Nation's official links before publishing.
- To keep the current Netlify URL, deploy to the existing Netlify project rather than creating a new site.
